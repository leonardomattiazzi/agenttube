Política de Privacidade

Última atualização: 24 de novembro de 2026

1. O que é o AgentTube

O AgentTube é uma ferramenta pessoal, usada pelo desenvolvedor para administrar os próprios canais do YouTube. Ela não é oferecida ao público.

2. Dados acessados

Quando o dono de um canal autoriza o AgentTube pela tela de consentimento do Google, a ferramenta acessa, pelas APIs do YouTube:

  • dados do canal e dos vídeos (títulos, descrições, tags, playlists, status);
  • métricas do YouTube Analytics (visualizações, tempo de exibição, retenção, inscritos e origens de tráfego);
  • comentários públicos dos vídeos do canal;
  • permissão para enviar e editar vídeos, capas, legendas e playlists do canal.

3. Como os dados são usados

Os dados são usados apenas para publicar e organizar conteúdo no próprio canal e para gerar relatórios de desempenho para o dono do canal. Não há venda, publicidade, criação de perfis nem uso para treinar modelos de inteligência artificial.

4. Armazenamento e compartilhamento

O token de acesso e os relatórios ficam salvos apenas no computador do desenvolvedor. Nenhum dado é enviado para servidores próprios nem compartilhado com terceiros, exceto o próprio Google/YouTube, que é quem processa as solicitações.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Ao revogar, o token salvo deixa de funcionar e pode ser apagado a pedido.

O AgentTube usa os Serviços de API do YouTube. Ao autorizar, você também concorda com os Termos de Serviço do YouTube e com a Política de Privacidade do Google.

6. Contato

Dúvidas ou pedidos de exclusão: github.com/leonardomattiazzi/agenttube/issues.

English summary

AgentTube is a personal tool. With the channel owner's authorization it uses the YouTube Data and Analytics APIs to upload and manage videos and playlists, and to read channel analytics and comments. Data and tokens are stored only on the developer's computer, are never sold or shared with third parties, and are not used for advertising or AI training. AgentTube's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at myaccount.google.com/permissions. AgentTube uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
